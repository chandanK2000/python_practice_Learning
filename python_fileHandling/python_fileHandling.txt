Important functions cheat sheet
Keep this as your revision reference.
Function / Module	Purpose
open()	Open a file
read()	Read content
readline()	Read one line
readlines()	Read all lines as a list
write()	Write content
writelines()	Write multiple strings
tell()	Get cursor position
seek()	Change cursor position
close()	Close a file
flush()	Flush buffered content
with open()	Automatically close a file
os	File and directory operations
pathlib	Object-oriented path operations
csv	CSV file handling
json	JSON file handling
