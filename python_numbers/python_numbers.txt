------------------------------------------------------------

Level 1 – Beginner (1–15)

Focus: Basic numbers, variables and arithmetic operators.

1. Create two integer variables and print their sum.

2. Create two float variables and print their difference.

3. Multiply three numbers and display the result.

4. Divide two numbers and display the result.

5. Find the remainder when 25 is divided by 4.

6. Find the quotient when 25 is divided by 4 using floor division.

7. Calculate the square of a number.

8. Calculate the cube of a number.

9. Calculate the average of five numbers.

10. Swap two numbers using a third variable.

11. Swap two numbers without using a third variable.

12. Convert an integer into a float.

13. Convert a float into an integer and observe what happens to its decimal part.

14. Create a complex number and print its real and imaginary parts.

15. Take two numbers from the user and perform all five arithmetic operations: +, -, *, /, //.

------------------------------------------------------------

Level 2 – Intermediate (16–30)

Focus: Conditions, number properties and mathematical operations.

16. Check whether a number is positive, negative or zero.

17. Check whether a number is even or odd.

18. Find the largest among three numbers.

19. Find the smallest among four numbers.

20. Check whether a number is divisible by both 5 and 11.

21. Check whether a given year is a leap year.

22. Calculate the absolute value of a negative number without using abs().

23. Round a float number to 2 decimal places.

24. Find the power of a number without using the ** operator.

25. Find the square root of a number.

26. Calculate the factorial of a number.

27. Print the multiplication table of a given number.

28. Find the sum of the first N natural numbers.

29. Count the number of digits in an integer.

30. Reverse a given integer. Example: 12345 → 54321.

------------------------------------------------------------


Level 3 – Advanced (31–45)

Focus: Number theory, mathematical logic and problem-solving.

31. Check whether a number is prime.

32. Print all prime numbers between 1 and 100.

33. Find the HCF/GCD of two numbers.

34. Find the LCM of two numbers.

35. Check whether a number is a perfect number. Example: 28.

36. Check whether a number is an Armstrong number. Example: 153.

37. Check whether a number is a palindrome. Example: 121.

38. Check whether a number is a strong number. Example: 145.

39. Find the sum of digits of a number.

40. Find the product of digits of a number.

41. Find the second-largest number in a list without using sort().

42. Generate the Fibonacci series up to N terms.

43. Convert a decimal number into binary without using bin().

44. Convert a binary number into decimal without using int(value, 2).

45. Check whether a number is a neon number. Example: 9 because \(9^2=81\) and \(8+1=9\).

Level 4 – Real-world scenarios & logical challenges (46–60)

Focus: Applying Python numbers in practical situations.

46. Shopping discount: A product costs ₹2,500. Calculate its price after a 15% discount.

47. GST calculator: Take a product price and GST percentage from the user and calculate the final price.

48. Salary calculation: Calculate an employee's annual salary from their monthly salary.

49. Bank interest: Calculate simple interest using principal, rate and time.

50. Compound interest: Calculate the final amount using principal, annual interest rate and number of years.

51. Electricity bill: Calculate the bill using different electricity slab rates.

52. Temperature converter: Convert Celsius into Fahrenheit and Fahrenheit into Celsius.

53. Age calculator: Take birth year and current year and calculate approximate age.

54. ATM withdrawal: Take a withdrawal amount and calculate the minimum number of ₹500, ₹200, ₹100 and ₹50 notes required.

55. Time converter: Convert a given number of seconds into hours, minutes and seconds.

56. Digital clock: Take a number of seconds and display it in HH:MM:SS format.

57. Profit and loss: Take cost price and selling price and calculate profit, loss and percentage.

58. EMI calculator: Calculate monthly loan EMI using principal, annual interest rate and loan duration.

59. Number guessing game: Generate a random number between 1 and 100 and let the user guess it. Give higher/lower hints.

60. Mathematical calculator: Build a calculator that accepts two numbers and an operator, then performs the requested operation. Handle division by zero.
